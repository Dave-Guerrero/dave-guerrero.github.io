Work done

UX/UI

I spearheaded the UX research and discovery phase, which informed the creation of comprehensive user flows and wireframes for the new Raptor product pages. Following this, I designed the intuitive User Interface (UI), developing a full set of high-fidelity mockups and interactive prototypes to ensure a user-centric experience aligned with brand goals.

Web Development

I handled the front-end implementation from concept to launch, writing clean, semantic code using HTML, modern CSS (including responsiveness), and JavaScript. A critical part of this process was the seamless integration of the front-end code with the Craft CMS template structure, ensuring maintainability and efficient content management.

SEO Implementation

I implemented the necessary techniques to identify keywords for tracking and indexing, in order to ensure that the product launch quickly achieved organic traffic.

Marketing Tools Setup

I was responsible for setting up conversion tracking mechanisms and integrating the new pages with the Pardot CRM. This setup involved implementing tracking codes (via Google Tag Manager) and configuring lead capture forms to accurately measure conversion events and seamlessly push prospect data to the sales pipeline.
