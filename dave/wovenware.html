Executive summary

This project highlights the complete digital transformation of the Wovenware corporate website, focused on enhancing the brand’s market position and maximizing lead generation.

I led the entire redesign initiative, from initial concept to launch, successfully delivering an immersive and intuitive digital experience. My strategic blend of advanced UX/UI design and robust technical SEO was the driving force that significantly increased inbound lead volume, solidifying the company’s market presence and directly supporting core marketing goals.

I was directly responsible for the front-end implementation of the entire redesign, creating clean, semantic code and adhering to best development practices. I led the hybrid integration of the code with the CMS platform, optimizing the structure to ensure scalability and exceptional performance. A key focus was improving the Core Web Vitals, achieving positive results that significantly boosted the site's speed and overall optimization.

Work done

UX/UI

I spearheaded the creation of the new information architecture and user flows, culminating in a complete visual redesign. The focus was on delivering an intuitive and engaging user experience that clearly communicates Wovenware's value proposition, utilizing modern design standards to ensure high visual quality and functional performance.

Web Development

I oversaw the entire front-end development, ensuring the new design was executed with clean, responsive, and cross-browser compatible code (HTML5, CSS3, JavaScript & Silverstripe CMS). I managed the integration of the code with the existing CMS infrastructure, delivering a scalable and maintainable foundation for all new content and features.

SEO Implementation

I implemented a comprehensive technical SEO strategy as part of the redesign, including optimizing site structure, improving Core Web Vitals, and implementing advanced Schema Markup. This technical focus was crucial in boosting organic visibility and driving a significant increase in qualified traffic and lead generation.

Marketing Tools Setup

I contributed to achieving company marketing goals by configuring analytics and tracking tools (e.g., Google Tag Manager) to accurately measure user engagement and conversion rates across the redesigned site. This setup provided actionable data used to continuously optimize the digital experience post-launch.
